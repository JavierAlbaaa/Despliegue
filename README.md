# Proyecto Java - Nivel 1 DAW

App de consola con menú que practica los contenidos básicos de Java.

## Requisitos previos

- [Git](https://git-scm.com/)
- Java Development Kit (JDK) 11 o superior. Compruébalo con:
```bash
  java -version
  javac -version
```

## Estructura

- `Main.java`: menú (`do-while`, `switch`, `Scanner`) y métodos auxiliares.
- `Calculadora.java`: métodos estáticos (operaciones, factorial, primo, Fibonacci).
- `Cadenas.java`: métodos con `String` (invertir, palíndromo, vocales).
- `Estudiante.java`: clase con atributos, constructor, getters, array y métodos.

## Instalación

1. Clona el repositorio:
```bash
   git clone https://github.com/JavierAlbaaa/Despliegue.git
   cd Despliegue
```

## Compilar y ejecutar

Desde la raíz del repositorio:

```bash
cd src
javac *.java
java Main
```

Se mostrará el menú en la consola. Introduce el número de la opción deseada y pulsa Enter.
